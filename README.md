# YT Music to Spotify

## Overview

**Description:** Aim of the project is to automate the copying of user's youtube playlist to spotify playlist. This is achieved with pytube and spotipy libraries. 

## Table of Contents

1. [Installation & Usage](#installation)
2. [Features](#features)
3. [Contributing](#contributing)

## Installation & Usage

**Instructions:** 
1) Make sure python3 is installed
2) run the requirements.txt file to install the required libraries
3) create a spotify app on https://developer.spotify.com/
4) Get the Client ID and Secret code and add them to a dotenv file
5) Change the placeholders for playlist URL and name for spotify playlist with the apt ones



## Features

**Main Features:**  Can read Titles of any youtube playlist without the need of getting a token from youtubeApi. Spotipy adds most of the music present in the playlist.
